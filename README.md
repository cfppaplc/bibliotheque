# Bibliothèque des livres animés — Pavillon de l'Avenir

Conçu par Jeremy, enseignant.

- `index.html` : la bibliothèque (page d'accueil du site)
- `livres/` : un fichier HTML par livre, téléchargé seulement quand on l'ouvre
- `plans/` : les dossiers de plans d'exercice (PDF + image de secours)
- `accueil.html` : le tableau d'accueil de classe, seul (lien direct)

Pour ajouter un livre : déposer le fichier dans `livres/` et ajouter son bloc dans la liste `LIVRES` de `index.html` (le champ `fichier` = nom du fichier sans `.html`).
