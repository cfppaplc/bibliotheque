Des outils à faire en classe avec les iPad des élèves. L'iPad de l'enseignant sert de télécommande, le tableau affiche l'écran de classe, et chaque équipe scanne un code QR. Aucun compte n'est nécessaire pour les élèves.

Comment ça marche

1Ton iPad : la télécommandeOuvre le simulateur et choisis « Télécommande ». Un code à 6 chiffres et un code QR s'affichent.
2Le tableau : l'écran de classeOuvre la même page sur le tableau, choisis « Écran de classe » et tape le code.
3Les iPad des élèvesChaque équipe scanne le code QR et écrit son nom. Son iPad devient un panneau d'alarme.
4À toi de jouerMode libre pour démontrer, ou « Lancer le défi » pour les 8 missions.
